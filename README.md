# Расписание МГУ → iCloud Calendar

Утилита запускается на вашем Mac, получает расписание вашей группы (сейчас — `111б_РиСО`) и обновляет только отдельный iCloud-календарь `Расписание 111б_РиСО`. Apple ID и пароль не требуются: macOS Calendar синхронизирует изменения сам.

## Чистая установка

По умолчанию проект можно разместить в одной папке «Документы/Расписание МГУ». Там будут находиться код, настройки, состояние синхронизации и экспорт для подписки. Python, дополнительные пакеты и Apple ID не нужны: используются только встроенные возможности macOS.

    ./deploy_to_documents.sh

Чтобы выбрать другое место, передайте путь, например: ./deploy_to_documents.sh "/путь/к/папке".

Единственный файл вне папки проекта появляется после установки ежедневного запуска: ~/Library/LaunchAgents/ru.msu.philos.schedule.plist. Это стандартный механизм macOS; удалить его можно командой ./uninstall_launchd.sh из папки проекта.

## Первый запуск

1. Откройте Terminal и перейдите в эту папку.
2. Запустите `./install.sh` один раз: он лишь сделает сценарии запускаемыми.
3. Выполните `./run.sh --dry-run`. Утилита получит расписание с портала и покажет число занятий.
4. Выполните `./run.sh`. Утилита обновит единый ICS-файл; Calendar при этом не изменяется.
6. После успешной проверки установите ежедневный запуск: `./install_launchd.sh`.

## Команды

```sh
./run.sh --dry-run
./run.sh
./run.sh --export-ics
./run.sh --calendar
./run.sh --from 2026-09-01 --to 2026-12-31
./run.sh --no-notify
```

Утилита получает таблицу напрямую с портала и обновляет локальный ICS-файл. Если сайт недоступен или изменил формат, предыдущий файл и состояние **не изменяются**. Параметр `--calendar` оставлен для редкого ручного импорта в локальный Calendar.

`--export-ics` создаёт файл для будущей подписки, но не добавляет занятия в Calendar и не меняет его.

Если портал не открывается при включённом VPN, выключите VPN перед ежедневной проверкой. Если это неудобно, укажите в `config.toml` локальный адрес прокси вашего VPN (например, `http://127.0.0.1:7890`) в поле `proxy_url`. Пароли в конфиг не записывайте.

## Настройка портала

Проверенная конфигурация для `111б_РиСО` уже записана в `config.toml`: группа имеет ID `1886`, факультет «Бакалавриат» и первый курс. Утилита последовательно выбирает их в той же форме, что и Safari, и запрашивает период семестра.

Если сайт перестанет открываться из-за VPN, настройте правило маршрутизации для `cacs.philos.msu.ru` в вашем VPN-клиенте. Утилита будет использовать тот же сетевой маршрут, что и обычный `curl` на Mac.

## Будущая подписка Apple Calendar

После каждой успешной синхронизации обновляется готовый файл `exports/msu-111.ics`. Для GitHub Pages используется сценарий `publish_github.sh`: он копирует файл в `site/schedule.ics`, делает коммит и отправляет его в репозиторий. GitHub Pages затем раздаёт файл по HTTPS, и любой человек сможет выбрать в Apple Calendar «Новая подписка на календарь».

## GitHub Pages

Репозиторий должен быть публичным, потому что ссылка подписки не требует авторизации. В корне репозитория оставьте папку `site` и `.github/workflows/pages.yml`; после первого push в настройках репозитория включите Pages через GitHub Actions. На Mac расписание обновляется так:

    ./sync_and_publish.sh

GitHub Actions только публикует уже полученный файл. Сам портал запрашивается с вашего Mac, поэтому GitHub не зависит от блокировки IP за пределами России.

## Безопасность

- Управляются только календари, перечисленные в `config.toml`.
- Внутри них утилита заменяет занятия только заданного семестра.
- При ошибке сети, пустой выгрузке или ошибке разбора удаление событий не запускается.
- Не добавляйте личные события в календарь `Расписание 111б_РиСО`.
