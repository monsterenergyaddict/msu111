# Автосинхронизация каталога лекций

Этот файл — точное правило для запланированной задачи Codex, которая обновляет `data.json`.

## Источники

1. Сначала проверить подключение Plaud через `plaud_get_current_user`.
2. Прочитать `site/111.ics` из `monsterenergyaddict/msu111`.
3. Прочитать текущий `site/lectures/data.json`.
4. Получить записи Plaud с начала учебного года до текущего дня. Все времена нормализовать к `Europe/Moscow`. Значение `duration` Plaud задано в миллисекундах; в каталоге хранить секунды.

## Отбор и сопоставление

- Запись короче 45 минут не попадает в каталог, кроме записи с ручной пометкой.
- Ручная пометка имеет формат `Лекция: [Название предмета] Тема`. Она создаёт запись с `source: "manual"`, даже если занятие не найдено в ICS.
- Обычную запись сопоставить с одним прошедшим событием ICS, с которым у неё максимальное пересечение времени. Если пересечения нет — пропустить.
- Для карточки, связанной с ICS, записать `lessonNumber`: это порядковый номер события за этот день после сортировки по началу, начиная с 1.
- Из `DESCRIPTION` события извлечь `instructor`, только если после строки с аудиторией остаётся уверенно распознанное ФИО преподавателя; иначе поле оставить пустым. Не придумывать преподавателя по содержанию Plaud.
- Для каждого `scheduleUid` оставить одну запись: сначала ручная пометка, затем запись с названием, содержащим «лекция», затем ту, что начинается ближе к началу пары, затем более длинную.
- Уже опубликенные карточки не удалять автоматически. При изменении названия или готовности заметки обновлять существующую карточку с тем же `plaudFileId`.

## Содержание

- Для каждого нового кандидата и каждой карточки со статусом `processing` запросить AI-заметку Plaud.
- Не получать и не публиковать аудио, полный транскрипт, временные `data_link` или персональные поля.
- Если заметка доступна, создать краткое содержание из 2–4 предложений и максимум четыре тезиса, строго по заметке; статус `ready`.
- Если заметки нет или она пуста, хранить пустые `summary` и `topics`, статус `processing`.

## Запись в GitHub

- Валидировать, что каждая карточка содержит `plaudFileId`, `startedAt`, `course`, `status` и URL строго вида `https://web.plaud.ai/file/<id>`; у карточки из ICS также должен быть `lessonNumber`, а `instructor` остаётся необязательным.
- Обновлять `updatedAt` и коммитить `data.json` только при содержательном изменении.
- При отсутствии изменений не создавать коммит и не отправлять сообщение.
- При ошибке Plaud/GitHub или неоднозначном совпадении не портить существующий JSON; сообщить только о проблеме.
